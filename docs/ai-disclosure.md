# Appendix — AI Tool Use Declaration (BT3)

| Stage | Tool | Purpose | Student review / responsibility |
|---|---|---|---|
| Repository review and test planning | ChatGPT | Helped inspect repository files, identify inconsistencies, and structure the test plan. | The student must review the findings against the actual repository and course rubric. |
| Code improvement | ChatGPT | Assisted with drafting FastAPI validation, SQLite persistence, Docker configuration, and automated tests. | The student must understand, run, debug, and take responsibility for the submitted code. |
| Technical documentation | ChatGPT | Assisted with drafting the Test Plan, Test Report, Bug Log, Deployment Guide, Security Checklist, API documentation, and README. | Results are reported only when executed; Docker and clean-machine evidence must be captured by the student. |
| Final verification | Pytest / GitHub Actions | Executed automated tests and CI checks. | The student should review actual terminal and GitHub Actions output before submission. |

AI was used as an assistance tool, not as a substitute for understanding or verification. No real customer records, passwords, API keys, or private credentials were intentionally supplied as test data.
